# Release v1.1.0

## Download
[pixid-auto-export-v1.1.0.zip](https://github.com/three-sixty-five-labs/pixid-lightroom-plugin-releases/releases/download/v1.1.0/pixid-auto-export-v1.1.0.zip)

## Changes
Compact UI layout for small screens, bump version

Streamline the Auto Export UI for smaller displays: reduce widths, spacing and margins; merge session and export controls; inline status; condense FTP credential fields into one row; combine batch/wait controls onto a single row; shorten several labels and button titles. These changes improve layout density and usability on compact screens. Also bump plugin VERSION from 1.0.1 to 1.1.0 (build 20260309). Files modified: AutoExportManager.lua, Info.lua.

## Installation
1. Download the ZIP file above
2. In Lightroom: File → Plug-in Manager → Add
3. Select the downloaded ZIP file
4. Access via: File → Plug-in Extras → pixid Auto Export
